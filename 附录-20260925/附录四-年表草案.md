## 〇、先说结论

1. **骨架沿用 P1 的方案甲**：卷二第二十至二十七章整体落在第二年八月到腊月，其余不动。本稿按这个骨架排出第一年到第十六年的逐季年表（第三部分），并补了 P1 没排到的几段：卷四林若谦与墨韵斋的年份、第四十七至四十八章的年份，以及前篇的接入。要改的字眼共约三十处，集中列在第七部分。
2. **前篇能把陌陌钉到端木朝的"元和"纪年上：第一年就是元和二十二年。** 依据有四条：①筱言卒于元和三年冬（执手 L11132、L11155、L11177）；②"今年，是那墓中人去世的十八年了"，一个月后木先生下葬（执手 L11234、L11247）；③逍遥"今年十八岁"（执手 L11251）；④陌陌里阡陌十九岁，逍遥"只比你略略小一岁"（L175–179、L2381）。由此推出：**逍遥到大理的时候，丧父才两三个月，正在孝中。** 这与 v3 L5643"逍遥爹去得早，他是半在这座府里长大的"直接冲突。
3. **"永平"在 v3 全书一次也没出现。** v3 唯一的改元，是第四十章新君即位时的"开春改元"（L5999），落在第七年。如果永平就是这位新君的年号，青冥殁于第十五年秋末，也就是**永平九年**，年三十五。甲案的实质（北疆、秋末、三十五岁）全部成立，只有"十二年"这个标签要改成"九年"。要按字面保留"永平十二年"，永平元年就得落在第四年，可第四年大理、端木两边都没有改元，只能另加设定（备选方案见 1-3）。本稿推测，"永平十二年"和卷五小标题里的"八年三月"（L6469），都是第四十章新写之前、按旧骨架算出来的（存疑）。
4. **村居一冬**：第三年冬月中下旬出大理，腊月初病倒，腊月十二看日照金山，腊月廿三开字摊，除夕打跳，第四年正月初一倩儿到，正月初五前后离村，前后约四十天。有一处暗合值得您知道：**腊月十二正是莫筱言的生辰**（执手 L2526、L10417），逍遥带阡陌看日照金山那天，是他娘的生日。
5. **青冥**：按"比阡陌大两岁"算（L399、L3851、L4419、L6885 四处一致），他第一年二十一岁，第十五年秋末殁于北疆，三十五岁。关键在于第四十七章阿枝出嫁那一年：倩儿"如今是年年要来的"（L6699），可见已经不是她头一回来，这一年应是第十五年。这样读，第四十八章的"那年秋天""那年秋末"都在第十五年，**终章的年份不必改**，与 P1 的读法不同（P1 把阿枝出嫁放在第十四年，所以要把 L6795 改成"又一年秋末"）。只有 L1469"他十九"和番外 L7027"二十九岁了"必须改。
6. **最硬的五处冲突**：卷二的月份与国后孕期；卷一揭面与《秋灯冬雪》的先后；永平标签；逍遥丧父的时间和在哪里长大；卷四第四十章与第四十一章的时间倒挂。详见第六部分。

## 一、纪年约定

### 1-1　相对纪年

- **第一年**：夜宴那一年。阡陌十九岁（"爹爹离世那年，你刚满十六岁"，姐姐又说"一晃三年了"，L175–179）。
- 公式：阡陌岁数＝18＋N（第 N 年）。

### 1-2　端木纪年（元和）

- 第 N 年＝元和（21＋N）年。第一年＝元和二十二年，第四年＝元和二十五年。
- 元和帝就是逍遥的伯父（L5663）。第四年正月阡陌给他诊脉，说"一年。将养得好，两年"（L5655）。v3 没写他卒于哪一年，所以第五年以后的端木年号不详。
- 旁证：执手的元和元年，子轩十八岁、筱言十六岁（执手 L90，zs_1）；陌陌第一年，赵凌云"已近四十"（L225），也对得上。

### 1-3　大理纪年与"永平"（请拍板）

- 第一至第六年：国主段正彦在位，年号全书未出现，可以一直不出现。
- 第六年腊月廿九国主崩，"开春改元，新君即位，年十岁"（L5999）。这是全书唯一的改元。
- **推荐方案：永平＝新君（麟儿）的年号，永平元年＝第七年。** 正文一字不用改，只把甲案的标签改成"永平九年"，L6469 的"八年三月"删掉，或改"永平四年三月"。
- **备选方案（保留"永平十二年"字面）**：永平元年＝第四年，设定为段正彦平定董氏之乱后，次年改元"永平"，新君即位时沿用不改。代价有三：L5999 删掉"改元"二字；L6469 改"七年三月"；卷三最好补半句改元（比如第二十九章"春信"一节末尾）。"新君沿用先帝年号十余年"在史例上很少见，所以不推荐。
- **推测（存疑）**：假如永平元年＝第三年、青冥比阡陌大三岁（L1469"我十六，他十九"），那么"永平八年三月"正好是念心满月（第十年三月），"永平十二年"正好是青冥三十五岁（第十四年），而第四十八章"那年秋末"也不用动。三处同时吻合，很像旧骨架留下的痕迹。那个骨架需要新君在第三年即位，而新写的第四十章已把国主崩移到第六年腊月（麟儿十岁），所以回不去了。

### 5-2　前篇带来的时间冲突

1. **逍遥丧父的时间和在哪里长大**：L5643"逍遥爹去得早，他是半在这座府里长大的"。执手是紫竹轩长大、十八岁丧父（执手 L11251–11252、L11283）。最小改法：改成"逍遥十八岁送走了爹，舅舅把他接进京来——这座府里，有他住过的屋子"。随之而来的是：第一年他正在孝中。v3 目前一句没写（L1887 的口气像是"早已过世"）。这不必改，但可以用：一个刚出孝，一个正在孝中（阡陌 L175，逍遥推算）。《先声》若重写，清明在山里设香案遥祭双亲，时间刚好对得上（P1 也提过）。
2. **逍遥的出生月份与"早产"**：L5735"去国八月；王妃却于次年三月诞子"，L5753"故而七月早产"。执手是夏末足月生（执手 L11039、L11091），夫妻只分开"一个多月"（执手 L9961）。改法请见第九部分第 3 条。若保留 v3 的写法，逍遥生于元和三年三月，第一年三月他就满十九岁了，"只比你略略小一岁"会显得牵强。
3. **年号**：L5751"太医院元祐某年的旧档"应改为"元和二三年"。执手作"元和"（执手 L8321），而"元祐"是宋哲宗的真实年号。
4. **"二十年前"**：L5683 与 L5755。宫变是元和二年，到第四年是二十三年；临风之母中毒更早，在先帝朝。建议 L5683 改"二十多年前"，L5755 改"此毒出自宫闱，先帝朝一回，元和初年一回"。
5. **萨仁**：第四年十三四岁，生于元和十一、十二年前后（推）。若"父汗"是苏赫（执手里苏赫在杭州吃过雪糕，执手 L1565），他与玎宁成婚已经十年左右才有这个女儿，说得通。"到老都念着南边"（L5721）的"老"，指的是四十多岁的苏赫，也说得通。这一条不是冲突，列在这里备查。
6. **两个生日**：筱言生于腊月十二（执手 L2526、L10417），子轩生于十一月十五（执手 L10024、L11688）。陌陌第三十三章看日照金山正是腊月十二（L5243）。见第三部分"村居一冬"。

## 六、时间矛盾与缺口清单

> 严重度：**高**＝不改，年表就排不下去；**中**＝读者算得出来的错；**低**＝细读才会发现，或者是约数。

### A. 骨架级

- **T01［高］卷二的月份与国后孕期。** L3589、L3599 把婚期定在十月初十，"还有两个月"。可 L3899"婚期定下的第七日"之后，接着就是 L4035"三月末的风"、L4061"四月里"、L4255 和 L4315"四月十七／五月初二／五月初三"。国后第二年端午后已经有孕（L1851、L1959），L2863、L3089 夏天孕吐，L4019"三月末"才有胎动，L4505"金桂"时节才生产，孕期超过一年。
  → 方案甲：E13 到 E17、E19。改完以后，受孕约在三四月，端午后发现，夏天孕吐，八月末胎动（约五个月），腊月生产，全部合理。
- **T02［高］卷一揭面与《秋灯冬雪》。** 短章写了秋冬（L1747–1819），第八章却"已过端午"（L1851），第十章又说"隔着半年"（L2331），赵将军"刚刚启程回朝"（L2303，他在 L1557 就已回京）。
  → 第八至十章定为第二年五六月。改 E6（"隔着半年"改"隔着一年"）、E5、E34（番外《方子》L6981"这半年"）。L2315、L2343 两处"半年来"可以保留：《名头》那本账是"那年冬天"才记起的（L1807），到第二年五月正好半年。这一点与 P1 不同，P1 主张 L2315 也改。
- **T03［中］楔子的年龄。** L25"十九岁那年……被夫家退了婚"。退婚在第二年八月，阡陌那时二十岁。
  → E1 改"二十岁那年"。退婚是谁提出的，另有问题，见 P1 的 N10。
- **T04［高］"永平"没有着落。** 甲案"殁于永平十二年"（fupan 第四部分），v3 全书没有"永平"。唯一的改元在第七年（L5999）。L6469 的"八年三月"用任何纪年都对不上念心满月那一年（第十年）。
  → 推荐：永平为新君年号，青冥殁于永平九年；L6469 删去"八年三月"。备选见 1-3。
- **T05［中］青冥比阡陌大几岁，番外里的年龄。** L1469"我十六，他十九"差三岁，L399、L3851、L4419、L6885 都差两岁。番外《曲水流觞》L7027 说他"二十九岁了"，那一年他其实二十二岁。
  → E3 改"他十八"；E35 改 L7027。
- **T23［中］卷四的时间倒挂。** 第四十章写第六年秋到第七年以后（太后殁、国主崩、改元），第四十一章"又是一年暮春"（L6019）却必须是第五年：林若谦"守了五年"（L6145），墨韵斋"第二年春末"林若谦就陪她来了（L7177），第五年暮春相思骨（L6129）。三处都要求林若谦第五年出现。可读者会把第四十一章读成第四十章以后的事，也就是第七年，那样逍遥的"五年"、苹果坛的"六年"就全乱了。
  → 最小改动是两处加年份锚：E40（L6019 改"他走后的第二个暮春"），E39（L5957"那年秋里"改"隔年秋里"）。另一个办法是把第四十章挪到第四十二章之后，改动更大。

### B. 年龄与年数

- **T07［中］母亲何时去世。** L379"彼时我父母皆在"、L381"我还记得母亲为我垂泪"，与 L1959"我出世时，娘亲便……不多日便辞世"相反。
  → E8：改 L379、L381（母亲早逝，与楔子"早逝的娘亲"一致）。
- **T08［低］指环戴了几年。** L1729"都已经六年了"。十四岁生辰到第一年是五年。→ E4。
- **T09［低］蛇咬过去几年。** L4417"那股腥苦，我十四年没有忘"。八岁到第二年冬是十二年。→ E18。
- **T19［低］"三十年"。** L5391"像把三十年积在胸口的什么"。逍遥这时二十一岁。→ E23 改"二十年"。
- **T24［中］玉儿的年龄。** L5981"玉儿三岁"（第六年腊月，应满四岁），L6129"玉儿五岁了"（第九年暮春，应满六岁）。这两个数恰好都对得上"玉儿生于第三年秋"，是旧骨架（卷二放在第三年）的遗痕。→ E27、E28。
- **T35［低］东篱看上去多大。** L1811"那不像五旬人的手"，其余各处都说三十上下（L497、L2075、L2153）。→ E36 改"那不像中年人的手"。
- **T29［低］"六年的药"。** 番外《晨曦》L7351"阎王的账，我赖了五年……喝了你六年的药"。三十到三十五岁是五年。若有意指二十九岁就开始吃她的药，可以不动；否则改"五年"。

### C. 季节与日期

- **T10［低］夜宴次日就入夏。** L447"初夏时节"、L471"夏日暑热"，而前一晚是"春末"（L35）。→ E2。
- **T11［中］赵将军什么时候走的。** L1557 第一年七月"将军已于今日回京"；L2303 第二年五月又说"你爹爹刚刚启程回朝"。→ E5。
- **T12［低］青冥什么时候出征。** L2559"三年前他走的时候……那一别，就是三载"，可第一章"才一年不见"（L307），番外说"第三年我去了边关"（L6919），都指向元和二十一年一别、一年后回来。番外又说"太医的'一年'，我已经多赚了一年半"（L6919），按元和十九年冬太医的话算，只多了小半年。→ E9，E37（可选）。
- **T13［中］醉骨草的"三个月"。** L4251、L4277"三个月前"。醉骨草要淬足三个月，九月十七下狱时就得成品，入库应在六月。→ E16。L4433"这三个月"（九月到冬月）是约数，可以留着。
- **T14［中］姐姐的信与玉儿提前命名。** L4223"等不到十月"（信在十月初送到），"麟儿玉儿尚幼"（孩子还没生、也还没取名）；L4019"玉儿的胎动"。→ E17、E12。
- **T15［低］"婚期将至"。** L3831 在婚期定下的头七天之内说"婚期将至"（L3899 才是第七日），婚期其实还有两个月。→ E10。
- **T17［低］荼蘼的花期与秋祭。** L4683 九月说"那架将开的荼蘼"，可荼蘼开在春末（L21、L6829）。L4833 的"秋祭"排到了十月以后。若是有意（荼蘼"开晚"），建议让阡陌心里点一句"开错了时候"；否则改"那架开败了的荼蘼"。
- **T18［低］青冥回城。** L3885 八月中说"大概就在这几日"，他却十月初才"从城门口直接过来"（L4187）。→ E20 改"怕是要入秋以后"，或者不动：天牢里那瓶军中金疮药（L4137）可以是军驿捎来的。
- **T20［中］"二月末"与"二月廿八"。** L5791"事毕，已是二月末"，之后还要去孤山、在紫竹轩"住了几日"，而启程是二月廿八（L5835），排不下。→ E24 改"二月初"。P1 建议"二月中"，但孤山在杭州，京城过去还要走一段路，改"二月初"更稳（存疑）。
- **T21［低］回程半个月与第四封信。** 三月中从北边登船，三月末到大理（L5871–5873），杭州到大理半个月很难走完（存疑，可改"四月末"，荼蘼仍在花期）。十二封信按月写（L4963），冬月动身，到三月末该拆到第四、五封了，L5881"第四封还没到日子"说不通。→ E25 改"四月那封还没到日子"。
- **T22［低］"立储未定"。** L5897 与 L5765"立皇太侄的旨意下了"矛盾。→ E26 改"储位未稳"。
- **T26［中］去束河的方向和路程。** L6561"出关往南，走了一月"。束河在大理北面，当年"出大理第五日"就到了（L4993）。→ E31 改"往北"。"一月"可以留着（带着三岁的念心，走得慢），也可以改"半月"。
- **T27［中］番外《方子》的刻簪时间。** L7007"开春我起刀刻簪"。第十八章八月已经"做了月余"（L3757），应是第二年六七月动的刀。→ E33。
- **T06［低］终章的倒叙。** L6795"那年秋末"排在腊月那段（L6793）之后。按本稿的读法（阿枝出嫁在第十五年），它就是同一年的秋末，年份不用改。只是读起来像时间倒流了，可以把 L6795–6797 挪到 L6793 之前（E32，可选）。

### D. 与执手的冲突（详见第五部分）

### E. 缺口（原文没交代，年表只能推）

- **T34［低］**

  2. 元和帝卒于哪一年、端木新帝用什么年号，都没写。

## 八、年表定下之后，卷首清单里的"小件"各落在哪一年

- **凤煞**（第二十章，第二年八月）。老者说的"当年"，就是第十三章姐姐入宫那一年术士到郑家（约元和十五年秋，推，L2775），那时阡陌十二三岁，老者已经见过她脸上的胎记。"三年前，先生也是这么说的"（L3937），指的是董恪敬元和二十年（第-1年）问卦。P1 的改稿"老朽当年见过"与年表正好相合。
- **庄生晓梦引子**（第四十四章开头，第九年入夏以前）。同一年冬天，他"又开始雕木头了"（L6429），梦里阳光下雕簪的人与此首尾相扣。第四十二章末（第九年暮春，L6129）已经有一场梦，两场梦相隔一两个月，要防重复。
- **唤儿**：第五年暮春随林若谦第一次露面（L6071），第九年暮春下相思骨。她称阡陌"小姐"的三处（L6137、L6145、L6157）都在第九年。这时阡陌已经辅政两年多，称"郑姑娘"都嫌轻，称"先生"最合身份（存疑，请定）。
- **吴越**：约元和十五年秋，姐姐入宫，吴越随沈王爷戍边。他战死在第一年到第二年夏之间，第二年六月死讯随玉观音送到（L2771–2787）。第三十九章"针石不及"名单里的那一句（L5935）在第五年。
- **老夫妇传说**：渔村那对纳西老夫妇是第十八章追述的，事在第二年七八月（L3789–3801）。束河巷尾那对"极老极老的夫妇"在第十三年夏出现（L6607），前后相隔约十一年，"极老"对得上。若要写成同一对人，需要交代他们从洱海边回了丽江老家。
- **五卷卷名**可以参考各卷的时间跨度：卷一，第一年春到第二年八月；卷二，第二年八月到第三年二月（第十九至二十八章），另含第三年九十月（第二十九章）；卷三，第三年冬到第四年冬；卷四，第四年冬到第九年冬；卷五，第十年到第十六年。

## 九、请您拍板的五件

1. **"永平"取哪一种。** 推荐：永平是新君年号，青冥殁于永平九年，正文不用改。备选：保留永平十二年，要改 L5999 删"改元"，并补一句平叛后改元。
2. **逍遥来大理时是否在孝中。** 照执手算，是。v3 要么改 L5643，接受"十八岁丧父"；要么在前篇之外另立一说。前一种与前篇一致，而且能给第一卷补动机（为什么南来、为什么戴假面、为什么"念家"）。
3. **逍遥的生日与第三十七章的谣言。** 一种是照执手，改谣言的结构：宗正寺说"王妃独自北上科萨数月，归来即有孕"，阡陌拿科萨萨满"十一月已有一个多月身孕"的旧档反驳（执手 L9957–9961），萨仁的父汗使团正好在京里作证。另一种是保留 v3 的"七月早产"，那就要接受逍遥生于元和三年三月，与前篇不一致。
4. **卷四的时间倒挂**：是加两处年份锚（E39、E40），还是调整第四十章的位置。
5. **喜堂定在哪一天**：是否就用原定的十月初十（第二年）。
