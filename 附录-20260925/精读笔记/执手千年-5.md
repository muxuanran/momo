## 0. 本段一句话概括

麝香案当夜，从身后抱住筱言的是临风（4987，接 zs_4 的悬念）。他叫她"言"，这是只有叶枫才叫的名字；筱言回他"你知道的，我有子轩"。子轩去山东办差五十九天，三月十五夜里回来，两人把心意说定。随后几件事一齐压过来：山东赈灾不顺，库银不够；晟王爷开价，出钱出兵，条件是安安郡主嫁给子轩。秀儿、安安、月梅先后警告筱言。筱言因"血寒之症"服药，药里却被兰儿奉丽贵妃之命掺了慢性毒，兰儿还说此事"太后默许"。筱言毒发血崩，临风救了她。为了让子轩脱困、保全兄妹，她决意放手：当着子轩的面抱住临风，谎称自己真正爱的是临风。临风当场向太后请旨赐婚，太后顺水推舟，子轩只说了一句"我祝福你"。还镯时玉镯落地，碎成几段。筱言哭哑了嗓子，失声，自名"莫言"，被临风带到山中桃花居静养。在那里，老仆石伯指着一园白花说："这荼蘼花一开，就再没有别的花了。"懿旨下来，封她为南亲王妃；同一天，子轩点头答应娶安安，婚期定在"下月十五"。本段收在筱言在临风掌心写下一个"心"字，决定"努力真心"。

## 2. 人物设定事实表

### 莫筱言
- **称呼／化名**：筱言；临风叫她"言"（4994、5016、5506 等），这也是叶枫对她的叫法（4994、5002）；自称"奴婢"（5130、5246）；懿旨称"宫女莫筱言"，封"南亲王妃"（5969）；小荷改口叫"王妃"（5988），又叫"姑娘"；失声后自名"**莫言**"（5881，章名即《莫言》5779）。附注·全书检索：执手4000–4001，子轩化名"木子轩"时，替女扮男装的她取名"莫言莫公子"。可见"莫言"最早是子轩起的名字，本段她又拿来自称。
- **身份**：书库宫女，誊写新进书目（5111、5219–5220），轮值夜班（5039）；"虽为罪籍"（5969）；懿旨后成为待嫁的南亲王妃（5969）。
- **年龄**："现在莫筱言应该是十七岁"（5235）；小荷"我们本是同样年纪"（5911）。
- **身体**：畏寒、月事不净，王太医诊为"血寒之症"，"外感邪气可能是长久受凉所致"，另有"思虑过甚"（5290–5300）；她自推病根是原主"常年用冷水洗衣服"（5329）；中慢性毒后"状况看似月事中的血崩"（5529）；"毒也未清尽"（5841）；失声，"心脉受损"（5874）；削梨割破手指（5994）。**这是本段对陌陌最要紧的一组身体设定**，见第4节。
- **医术**：不懂医。听太医讲医理"头都大了"（5298），拿着药方"一点也看不出头绪"（5328）。本段的医者是王太医、红叶、璎珞。
- **才艺与学识**：弹古筝，爱弹《梁祝》中的《化蝶》，小时候学过钢琴（5055）；诗词张口就来（第3节有清单）；有文学史眼光，知道卓文君数字诗"本就是后来元曲的风格"（5073）。
- **现代记忆**：叶枫被出卖、失意落泪（5003）；"房子车子工作论文"的烦恼（5895）；大学时玩游戏、看武侠小说（6051）；梦回学校，同学约她春游烧烤（6007–6010）；常拿电视剧、拍戏作比（5471、5969、5970）。
- **随身物**：子轩的信，一直揣在怀里（5058、5954–5956）；月白玉镯，本段碎了（5751–5755）；妆盒里有长命锁、簪子、临风给的檀香盒（5950）；临风的羊脂玉笔（5911）。
- **关键经历**：与子轩说定心意（60章）→ 中毒（65章）→ 为了子轩和兄妹放手，谎称爱的是临风（66章）→ 奉懿旨许嫁临风（66、69章）→ 失声，自名莫言（67章）→ 到桃花居静养，初见荼蘼（68章）→ 在临风掌心写"心"（6064）。
- **本段去向**：住在桃花居，待嫁南亲王。

### 端木子轩（睿亲王；早年化名"木子轩"，被称"木先生"）
- **称呼**：子轩；"我堂堂睿亲王"（5153）；临风、秀儿叫他"二哥"（5129、5259）；他叫临风"四弟"（5128）；称皇帝"皇兄"（5083）；小冬子叫他"主子"（5154）；筱言心里叫他"**木先生**"（5676："初初遇见时候便有着天下最温和笑容的木先生"）。附注·全书检索：执手151"新来的木先生"，是子轩以账房先生身份初见筱言时的称呼。

- **誓言**："我们会有一生的时间一起看每个月圆"（5050）；"答应我，再不许出事"（5214）；"我端木子轩认定的，不会变的"（5385，筱言回忆）。
- **对指婚**：起初不答应（5383、5434）；被"退婚"后说"若这是你的选择，我祝福你"（5741），把碎镯一段段捡起（5754）；红叶看见他在书房拿着一件东西出神（5937，是什么没说，存疑，推测是碎镯）；最后"点头答应"娶安安，婚期"下月十五"（5981）。

## 4. 与陌陌的衔接

### ① 相合：执手原文能印证 v3 的说法

1. **荼蘼的源头就在这里。** 执手5896，石伯说"这荼蘼花一开，就再没有别的花了"；5898–5899，筱言讲荼蘼的寓意："荼蘼花开也就是一年花季的终了"，"荼蘼花开时，却正是我们的爱终结时"。王淇的诗在5109、5897出现了两次。v3 楔子21"只有荼蘼，开在春事将尽的时候"、v3 79"是荼蘼。旁的花赶着春天开，它偏不"、v3 6829"这花开在春末，是百花里最晚的一个"，都和它同出一源。**两书的立意正好相反**：母亲的荼蘼是"终了"，阡陌的荼蘼是"晚开"。这组对照可以在陌陌里明写出来，见第5节。
2. **"木先生"就是子轩。** 执手5676把子轩叫作"天下最温和笑容的木先生"。v3 649"学了木先生与木夫人"、v3 1877"木先生和木夫人在西湖边"、v3 1901、v3 5051"木先生的字"，都是把"木先生"当作丈夫或男子的称呼，与此相合。（v3 5807–5809 不合，见②。）
3. **西湖是两人定情之地。** 执手5046"我们一起在西湖边看平湖秋月"，5679"想看你在西湖边悠然自得的样子"；v3 1877"遥想当年木先生和木夫人在西湖边看断桥残雪"同属西湖记忆。zs_1 记平湖秋月那夜在孤山南麓（执手1117–1241），所以两人日后隐居孤山是有来由的。
4. **《醉清风》就是"木夫人的曲谱"。** 执手5676"共弹一曲《醉清风》"，可与 v3 955"是木夫人的曲谱，这曲子最妙的当属所配的词"对照（zs_1 已论证）。本段又加了一笔："还有你唱的那曲子——永生难忘"（5048）。
5. **"赵将军便是莫筱言的兄长"（v3 173）。** 本段凌云是"赵大人"（5419），筱言叫他"哥"（5183），他说"天大的事情有你哥在呢"（5420），与 v3 173 相合。二人是继兄妹（zs_2、zs_3），没有血缘，所以 v3 2389"倩儿…同她却无血缘关系"也说得通。
6. **舅母＝红叶（推测）。** v3 3549"舅母待我如亲生"，v3 6683"一方旧砚——是舅母的遗物，她从紫竹轩的旧库里翻出来的"。本段凌云与红叶两情相悦（5175–5181），红叶照料筱言、救过她的命（5529、5943），又会医、会做菜、会养花，与"待我如亲生"的舅母形象契合。婚事要看后段，**存疑**。
7. **"王妃带毒成婚，带毒成孕"（v3 5753）有了病理来历。** 本段筱言先得"血寒之症"（5300），又中慢性毒（5525–5537），"毒也未清尽"（5841），"心脉受损"（5874）。v3 里逍遥"锥心散的毒是自娘胎带来的"（v3 611），体内还有一股"寒气"（v3 607）："寒"与"毒"两样，本段都已种在母亲身上。**只是本段的毒没有名字**，锥心散的出处见③。
8. **"此毒出自宫闱"（v3 5755）有来历。** 本段的毒由丽贵妃主使，"太后默许"（5566、5587）；附注·全书检索：执手7604，太后当年也用锥心散害死了临风生母。"宫闱用毒"这条线，与 v3 殿辩的说法合得上。
9. **"先睿亲王妃与临风过从甚密"（v3 5683）这个流言，在执手里有实据。** 本段筱言当着子轩抱住临风（5656），太后懿旨"特此赐婚，封南亲王妃"（5969），她又随临风出宫，住进他的桃花居（5894）。宗正寺要翻二十年前的旧账，一道赐婚懿旨远比"文墨往还"有分量。参见②第1条和第5节。
10. **"母亲为了他好而推开他"与"逍遥诈死"是同一个母题。** 本段筱言的逻辑是"若只能成为他的羁绊，我，放手！"（5598），"只要我消失，一切人都不会在有事"（5594）。v3 7159逍遥说"死人最干净"，v3 5897说他"连自己的死，都拣了叫所有人安心的死法"。母子两代做了同一种选择。本段还有凌云追问"可是真心"（5925）、"还可斡旋"（5939），可以直接移作 v3 里赵将军的台词。
11. **书库与《孤山十札》。** 本段筱言在书库誊写书目（5111、5219–5220），又能辨出数字诗是"后来元曲的风格"（5073）。v3 173说十札"尽是珍品…她却早有言明，皆是先人所作，怎奈我却全然找不到出处"。书库经历正好解释她知道哪些书这个世界没有（参 zs_3 2650"没有历史上的元明清"）。v3 4885、5851逍遥"伏案誊书"，也和母亲誊写书目相映。
12. **"同一张脸"的母题。** 本段临风长着和叶枫一样的脸（5034、5735）；v3 有逍遥的假面（v3 6973"我竟会妒忌一张我自己的脸皮"），又有"一个背影同我一般无二的人"（v3 7179）。替身、同脸，母子两代一脉相承。
13. **筱言十七岁。** 5235 与 zs_1 的"十六岁"相承。v3 说"他们只过了一年"（v3 173），本段无从印证，只能说本段人物年纪都很轻，是合的。

### ② 相冲：执手原文与 v3 对不上的地方

1. **"江南名士临风"（v3 5683）与执手人物不符。** 执手的临风是"端木临风"（5131），子轩的"四弟"（5128），南亲王（5004、5969），是皇子亲王，不是"江南名士"。v3 5753又另说"南郡王败走"，好像"临风"和"南郡王"是两个人。执手里二者是同一人（3785 南郡王升为南亲王）。**建议**：v3 5683改成"先南亲王临风"之类，与5753合为一人；或者明写宗正寺故意隐去亲王身份，另有用意。
2. **称号：南郡王还是南亲王。** v3 5753写"南郡王败走"，执手本段一律是南亲王，懿旨也是"封南亲王妃"（5969）。**建议**：v3 改"南亲王"；若想保留"南郡王"，需要补一句他后来被夺爵降等（后段是否如此，待核）。
3. **"木先生之墓"是娘的（v3 5807–5809）。** v3写左碑"木先生之墓"，逍遥说"娘的"，理由是"女子的书进不得书局，娘便把自己折进一个名字里"。可执手的"木先生"是子轩（5676；附注151），v3 自己在649、1877、1901也把木先生、木夫人分作两人。碑文和前文自相矛盾，又与前篇相冲。**可选改法**：(a) 左碑仍是"木先生"，改为爹的，右碑刻娘的；(b) 娘的署名换成"**莫言**"，这是子轩当年为她起的化名（执手4000–4001），本段她失声后又拿来自称（5881），"莫与之言"四字也合"女子的书进不得书局"的委屈。这样一改，fupan 所列"右碑碑文仍未点"也有了着落。
4. **宗正寺与宗仁府。** v3 用"宗正寺"（5683、5735、5753），执手本段是"宗仁府"（5564，应为宗人府）。同一朝代相隔二十年，机构名最好统一。这是小事，建议 v3 改"宗人府"，或者由您定夺。
5. **"先睿亲王某年奉使北庭，去国八月"（v3 5735）。** 本段子轩出京是去山东（5263），前后五十九天（5039），不是北庭，也没有八个月。这不算矛盾，但 v3 的"奉使北庭"要在执手后段找到出处（科萨在北方，可能对应，存疑），否则就是新设定，要自洽。
6. **v3 5535"临风把酒"撞名。** 这里的"临风"是词语，不是人名，但 v3 5683、5685、7159 里"临风"是有名有姓的人物，读者会看岔。建议改成"把酒临窗"或"对风把酒"。
7. **医术的来历要自洽。** v3 173说十札有"医学杂项"，本段筱言却完全不懂医（5298、5328）。建议在 v3 交代十札的医学部分出自舅母红叶或殷家医书，这正好接上 v3 6683"舅母的遗物…从紫竹轩的旧库里翻出来的"。

## 5. 可供陌陌扩充借用的素材

v3 卷二到卷五偏薄，卷四、卷五合计不到1.6万字（fupan 第三节）。下面各条按可以落到 v3 什么位置来排。

**A. 荼蘼两代：从"终了"到"晚开"**（执手5896–5899、5109）
- 素材：石伯那句"这荼蘼花一开，就再没有别的花了"（5896）；王淇诗；筱言的荼蘼释义："荼蘼花开时，却正是我们的爱终结时"（5899）。
- 用法：v3 楔子（21–29）和第一章荼蘼墙（79）已经立起"晚开"的意思。可以在卷四紫竹轩旧库那一章（v3 5797前后）加一页：逍遥或阡陌在十札或母亲手札的批注里，看到她写荼蘼是"终了"。阡陌当场或日后回应，"它不是开在终了，是开得晚"，把母亲的悲句翻成女儿的书名。终章（v3 6829–6841"荼蘼花开得晚"）可以再回扣一次。石伯如果到陌陌时代还在（存疑），可以让他成为紫竹轩或孤山的老花匠，墙根的荼蘼是他从桃花居移来的。这需要您拍板，属新设定。

**B. 母亲失声与"墨韵斋的哑巴"**（执手5857、5874、5881、5910、6064）
- 素材：哭哑失声，"心脉受损"（5874）；"不如叫莫言"（5881）；小荷摆上纸笔，"姑娘以后有什么就尽管写到纸上"（5910）；在临风手心写一个"心"字，再轻轻合上（6064）；红叶的诊断"失语之症，多半算是心病"（5943）。
- 用法：v3 墨韵斋一线里，逍遥装哑五年（7165），"铺子里备着纸笔，供客人同哑巴讲价"（7187），与母亲失声后以纸笔说话的情形如出一辙。可以在番外《墨韵》或第四十二、四十三章补一笔。比如逍遥自白"娘哑过一个夏天，我学的是她"（新写）；又比如认出那一刻，他在阡陌掌心写一个字，再把她的手合上，复现"心"字的动作。阡陌是医者，她说出"心病致喑"（化用红叶5943），比旁人更有分量。

**C. 碎镯与"再没有人问他讨还"**（执手5751–5755、5787、5937）
- 素材：还镯时镯子落地碎成几段，子轩一段段捡起，说"碎了……"（5754）；新月"像碎了的镯子"（5787）；子轩在书房拿着一物出神（5937）。
- 用法：v3 6683箱底有玉猪、旧砚，白玉蝉"这一回，再没有人问他讨还"。可以在紫竹轩旧库木箱里再添一个小布包，包着几段月白碎玉（碎镯最后落在谁手里，要看后段，存疑）。母亲还镯，镯子碎了；儿子的白玉蝉却再没人讨还。这组对照一句话就能落地。

**D. 殿辩的弹药：懿旨、脉案、药渣**（执手5969、5300、5537、5563、5587）
- 宗正寺的"证据"可以从"文墨往还"升级成**太后懿旨的底档**："宫女莫筱言…特此赐婚，封南亲王妃"（5969）。阡陌的反驳也就更难，更精彩（v3 5735–5755），卷四可以多出一整章。
- 阡陌作为医者，可以调出当年王太医的脉案（血寒之症，5300）和红叶、璎珞的解毒记录（5529–5537），证明"带毒成婚"由来已久。"药渣留证"（5563）也可以变成她查旧档的方法。
- "此毒出自宫闱，二十年前用过两回"（v3 5755）：一回是太后害临风生母（执手7604），另一回待后段核。本段丽妃在调经药里下毒、"太后默许"（5587），可以作为殿上"年长的大人们都记得"的第三件旧案，或者当作暗线。

**E. 赵将军（凌云）做活证人**（执手5197–5207、5393–5400、5925、5939）
- v3 里赵将军戏份很少（v3 219–235，另见5643）。本段他是唯一当面追问"可是真心"的亲人（5925）。建议卷四京城段让他对阡陌讲一次当年的事：她"推开"子轩，碎镯，懿旨，他托红叶带话"还可斡旋"。阡陌由此看懂逍遥后来诈死是在重走母亲的路（v3 7159"死人最干净"），终章那句"你和你娘一样"（新写）就有了分量。
- 凌云府第（5159–5172）可以就是 v3 的赵府（5643）：两进四合院，前院连翘、玉兰，后院花圃是舅母红叶的花，还有玉兰树下的石凳。倩儿可以带阡陌看"当年你公婆坐过的那张石凳"（5195、5209–5215）。玉兰还能和 v3 的"玉兰步摇"（4301、6533）呼应。

**F. 逍遥名字的出处："愿求半世逍遥"**（本段5869；全文见执手2、3716）
- 本段失声后，她提笔写"一杯香茗一卷书"，写了半句又停住，"那样的话再不会写，再不会期盼"（5869）。v3 全书没有"半世逍遥"。建议在念心取名那场（v3 第四十五章三朝）或紫竹轩旧库那场补一句：扉页上是母亲的手迹"一抹斜阳，一壶酒，愿求半世逍遥"，逍遥说"我的名字从这里来"。一行就能把前后两部书缝上。

**G. 萨仁：苏赫起给筱言的名字**（本段5930–5934；附注616–618、10082）
- 本段巴特尔、苏赫随科萨使团入京，筱言称苏赫"老朋友"（5934）。v3 的萨仁是"汗王的女儿"（v3 5767）。如果汗王就是苏赫（后段待核），女儿取名"萨仁"，就是在纪念当年那个"像月亮"的汉家女子。萨仁见阡陌时说"你脸上开着一朵花…野海棠"（v3 5715），又可以连到本段临风送的海棠（5107、5142）。建议在 v3 第三十六、三十七章萨仁一段加一句："我阿爸说，我的名字是借一个汉人姑娘的。"（新写，要以后段核实为前提。）

**H. 数字诗、灯花、数日子**（执手5063–5073、5079、5091）
- 母亲把相传卓文君的数字诗当情书（5063–5071）；"人都说灯花爆是报喜的"（5079）；"今天是你走的第五十九天"（5091）。
- 用法：v3 第二十九章的驿报和春信，可以让阡陌在十札的"诗词歌赋"卷里读到这首数字诗，旁边有母亲的小字"元曲风格，非文君作"（化用5073）；或者在逍遥"殁于雁回关外"后的五年里，阡陌也数日子（对照 v3 7201"第五年荼蘼开时，我盘了一回账"）。

**I. 其他可用的线头**
- **秀儿（怡宁公主）**："二哥会娶的人只有你"（5319）。v3 京城段若需要一位知道旧事的长辈女眷，可以请她出来，此时约四十岁。她生死如何，待后段核。
- **晟王爷与"三王爷"**：v3 5737、5755的三王爷"捻茶盖"，知道锥心散旧事。可以考虑让他是晟王府一系，或者与晟王爷有旧，这样能接上执手7747临风用毒剑伤晟王爷一事（后段待核）。
- **"你给我弹琴，听我说娘的事情，我们一起看桃花"（5005）**：临风吹箫、筱言弹筝（5056）。v3 东篱先生吹箫、阡陌抚琴（v3 1269、7291），箫这一脉在执手属于临风，不属于子轩（子轩弹筝，见 zs_1）。宗正寺可以拿"世子善箫，类南亲王"做文章（新写），逍遥则可以说箫是娘教的（存疑，要看后段筱言是否学过箫）。
- **子轩与安安的婚约"下月十五"（5981）**：v3 没有提安安。逍遥"唤赵将军作舅舅"，只有赵家亲戚，没有提晟王府外家，可见这桩婚事最后没成（推测，待后段核）。

## 6. 文笔观察

**本段特点**
1. **第一人称的穿越腔**：现代词和古装场面并用。"我堂堂睿亲王在你眼中都成了人口贩子了"（5153），"上了'贼车'"（5149），"电视剧看多了"（5471），"总觉得我们像在拍戏"（5969），还用打游戏"走错关键一步…满盘皆乱"来比人生（5939）。
2. **幽默和煽情落差很大**：前半部轻快，有杨公公那句"我是说你把册子拿反了！"（4978）、"救命啊，有人谋杀亲妹妹啊"（5194）、"手凉脚凉没人疼"（5120）。六十四章起急转直下，连写六章苦情。
3. **章末必附诗词或歌词**：几乎每章以一首古诗、纳兰词、流行歌词或网传诗收尾（5036、5361、5599–5624、5758–5775、5883、5960），以此代替叙述来收束情绪。
4. **大段内心独白和排比**："子轩，好想对你说……／子轩，好想握住你的手……／子轩，好想对你笑……"（5680–5682）；"为什么……为什么……"（5595–5596）。"心下一怔／心中一颤／心头一震"这类套语很密。
5. **靠物件承载情绪**：海棠从开到谢（5107→5887），玉镯碎（5752），新月像碎镯（5787），荼蘼（5896），这是本段最好的手法。
6. **错字和体例**：萧／箫（5056），"毛病"＝毛笔（5929），"知不住"（5519），"在不会"（5643），"随不是"（5073），珑月阁／珑秀阁（5237），宗仁府（5564），章号重复（5106、5217），"!!!!"（5775）。

**代表性短句**
- "海棠不能在正午日头下晒，会伤了叶子。"（5142）：以物写情，含蓄。这是本段最接近 v3 定稿文风的一句。
- "那弯月牙，就像碎了的镯子——月白色，碎了一地。"（5787）：借物收束。
- "这荼蘼花一开，就再没有别的花了。"（5896）：老仆一句家常话，托起整本陌陌的题眼。
- "莫与之言，若就此不再说话，不如叫莫言。"（5881）：拆字、自嘲，是早期文风里的机巧。

**对照 v3**：v3 的定稿文风已经收敛成白描短句，比如"殿里的静，换了一种质地"（v3 5755）。执手本段的情节骨架值得借（牺牲式的误会，懿旨，失声，碎镯，荼蘼），腔调不宜照搬：大段排比独白、章末引歌词、现代梗，与 v3 气质不合。借用时可取 5142、5896 这类"一句话落在物上"的写法。
