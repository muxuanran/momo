## 0. 本段一句话概括

筱言在字画行看到《虎》字落款，认出总督岳百川就是负心的状元父亲；子轩带她上孤山对西湖大喊。随后子轩的真身一步步露出来：他是端木子轩，新封的睿亲王，奉旨查"前朝积案"。冬至那天，子轩借"去看断桥残雪"把她支开，她与科萨两位王子苏赫、巴特尔踏雪看断桥，苏赫把亡妹萨仁的短剑送给她。回府时总督府正被抄家。岳百川认出女儿后自刺身亡，岳夫人当夜病逝。筱言与罪臣家眷一同被押解进京，腊月十二（生日）走到济南，听到乡音，用萨仁的短剑割腕。魂游中见到原主和羽君的一生，悟出"这一生你还没走完"，醒来后接受了子轩的吻，也认了赵凌云为兄。

## 2. 人物设定事实表

### 莫筱言（穿越者兼原主）
- **身份与血缘**：生父是总督岳百川，丙亥年状元（1399、1415–1416）；生母莫羽君（2232）。赵凌云是她的继兄（2618、2623）。岳芙蓉、岳玎宁都是岳百川与岳夫人的女儿（2308），所以是她同父异母的妹妹。
- **现代来历**：家在"2006年的济南"（2525），在北京生活过（1685、2071）。穿越前有过一段分手旧事（1717、1830–1833）。
- **本领**：会包饺子，厨艺是"我自己的"（2061）；书法和琴艺是原主身体自带的，她觉得"都是偷来的一般"（2061）。**不懂医**："只可惜我不是学医的"（1860）。不会武功（1532、1629），不太会骑马（1599–1601）。
- **性格**：倔强，"生平最讨厌的就是别人强迫我"（1584）；爱吃、会享受，"生活就是用来享受的"（1960）；遇事想逃（2354、2529），最后学会面对（2601、2631）。
- **身体**：原主体弱，走几步就喘（1936）；月事时受凉腹痛，昏倒两日（2166、2463）；割腕后留下腕伤（2530、2604）。
- **关键经历**：认父（2230–2232）；父母双亡当日在场（2247、2339）；被定为随罪臣家眷"入宫"（2418）；济南割腕后被救，悟到"这是我的前世"（2583）。
- **去向**：本段末在济南养伤，接下来随队进京、入宫（2471、2418）。

### 端木子轩（木子轩／木先生／睿亲王）
- **名号**："端木子轩"（1539）；睿亲王（2161）；府里人叫他"木先生"（车夫老张1386、福顺1665、凌云1851、小青2471）；科萨王子称他"端木兄"（1489）。
- **身份**：先帝之子（"父皇"，2165），当今皇上是他哥哥（"令兄"1507，"皇兄"2264、2413）。"这回来做了王爷"（1491），可见是新封的（推测）。
- **来杭州的真实任务**：查"前朝的积案"（2164）。木管家是他的人（2175），赵府管家与他密谈（1568），用意是支开筱言（1929）。
- **外貌与习惯**：常穿月白长衫，发带束发（1390）；抄家时穿藏蓝色朝服（2153）；只喝铁观音（1478）；**用中指轻点桌面答谢斟茶**（1482）；常揉眉心（1571、1923、2594）；替筱言揉开紧皱的眉头（1433）；给她夹菜（1517）。
- **本领**：武艺出众（1491、1502），会点穴（2257），驾车（2357）。去过草原，同科萨王子是旧识（1491、1516）。
- **心性**：想出世，"做一个世外人，一叶浮萍"（1484）；他有个秘密，不开心时就找地方大喊（1450–1452）；从不追问，"你想说自然会说"（1433）。
- **对筱言的誓言**："记得，有我在"（1454）；"我一定会护你周全的"（1760）；"我们不会做相隔银河脉脉不得语的那两个人"（1774）；"有个人会永远为你守护"（2425）；抄家那天说"我依旧是我，你还可以把我当作木先生"（2161）。

- **去向**：押解罪臣家眷进京（2471），在济南守着筱言醒来（2596–2609）。

### 赵凌云（总督府少爷）
- 岳夫人与前夫赵甫的儿子（2305；zs_1记为前朝将军赵甫的遗腹子，执手895）；"是功臣之后，不会受什么牵连"（2408）。

- 他出过"雪糕用雪水来做"的主意（1797–1803），也要过一句"若有想有人分享的风景时，记得我"（1823）。

### 岳百川（杭州总督）
- 丙亥年状元（1415），皇上赐婚给相府千金（1417）；《虎》字落款"岳百川于苏州"（1399）；外表"像个中年的教书先生"（1607）。

### 岳夫人（总督夫人，相国千金，名字未交代）

## 4. 与陌陌的衔接

### ① 相合（执手原文能印证 v3 的）

1. **【最强】雪糕：木夫人的"家乡特产"**
   - v3 5337：逍遥说娘"牛乳兑了糖，冻得实实的，拿筷子作柄…满府上下人人有份，连不相干的客人都有份。她递出去的时候说——尝尝，这是我家乡的特产"。
   - 执手这边逐项对得上：
     - 筷子作柄（1650、1663）
     - 分给全府（1656–1663）
     - 连"不相干的客人"苏赫、巴特尔都有份（1943–1954）
     - 原话"雪糕，尝尝，这是我家乡的特产"（1663）
   - v3 5383 做出"梅花的"雪糕，对应执手1651"一个是桃形的，一个是梅花的"。
   - v3 5355 说雪堆"比什么冰窖都大"，对应执手1650的总督府冰窖。
   - v3 5353"那它生来，就该拿雪做"，正好是赵凌云当年的主意（执手1797–1803）。
   - 小差别：执手用的是牛奶、奶酪加糖（1650），v3只写"牛乳兑了糖"，不算冲突。
2. **赵凌云是莫筱言的兄长，是逍遥的舅舅，与倩儿、逍遥没有血缘**
   - v3 173"赵将军便是莫筱言的兄长"；v3 5643"唤赵将军作舅舅"；v3 2389"倩儿是我舅舅家的妹妹，但我同她却无血缘关系"。
   - 执手本段落实了这层关系：凌云是岳夫人与赵甫的儿子（2305），筱言是岳百川与羽君的女儿，两人是继兄妹，没有血缘；本段末凌云认妹（2618–2623）。
   - zs_1 把这条列为"待后段"，现可**确认相合**。v3对"无血缘"的说法严丝合缝。
3. **"木先生"就是子轩**
   - 执手本段反复这样称呼：车夫1386、福顺1665、凌云1851（"跟木先生借你几日"）、子轩自称2161、小青2471（"木先生，不，睿亲王"）。
   - 与 v3 649、1877、1903 把"木先生与木夫人"当夫妇来写相合。
4. **睿亲王是端木氏，皇帝是他哥哥**
   - 执手：1539"端木子轩"、2161睿亲王、2264与2413"皇兄"。
   - v3：5663 逍遥称皇帝"伯父"，2347"睿亲王独子"。
   - 两边相合。本段的皇兄与v3临终的皇帝是否同一人，仍存疑，见②3。
5. **孤山隐居的种子**：筱言对子轩说"那你合该在孤山隐居的"（1487），子轩也有"做一个世外人"的心思（1484），又约"下次来时再细细看"（1472），正好指向 v3 173"隐居杭州孤山"。
6. **家乡之谜**：v3 5341 写"爹问过她一辈子——她只笑，不说"。执手本段里，筱言讲星座只说是"另外一个古老国度的传说"（1738），说雪糕是"家乡的特产"（1663），真实的家却是"2006年的济南"（2525），始终没对子轩讲明。相合。
7. **"有我在"是父子同语**：子轩说"记得，有我在"（1454）；v3 1977 逍遥说"陌儿…有我在"，v3 7049也有。可以看成一处有意的承袭。
8. **科萨国与"萨仁"这个名字**
   - v3 5705、5767–5769 有科萨公主萨仁。
   - 执手本段的萨仁是科萨小公主，已故（2117–2120），又是苏赫给筱言起的名。
   - v3 公主的名字与执手的小公主同名，衔接很好，但 v3 没交代来历，见第5节D。
9. **眼镜和水晶镜**：执手1984–1986，筱言向巴特尔解释眼镜是"两个薄薄的镜片"。v3 5775–5779，阡陌借"透光聚形之理"帮萨仁磨出水晶镜。这是天然的呼应，但 v3 目前把这门学问记在宫叔叔的杂记上，没有和木夫人挂钩。
10. **子轩去过草原**：苏赫说"这一年未见"，两人"回忆着草原的美好"（1491、1516）。这可以为 v3 5735"先睿亲王某年奉使北庭"提供可信的底子，但地名要统一，见②4。

### ② 相冲（或需说明）

1. **"木先生之墓"是谁的**（加强 zs_1 的判断）
   - v3 5807–5809 说左碑刻"木先生之墓"，是"娘的"，理由是娘"把自己折进一个名字里"。
   - 执手本段"木先生"只指子轩，出处见上条3。另外，"木"这个姓似乎是借木管家的掩护来的（2175）。
   - 建议照 zs_1 的方案改：父碑刻"木先生"，母碑另署；或另起一个笔名。
2. **断桥残雪不是两人合看的浪漫场面**
   - v3 1877 阡陌想象"木先生和木夫人在西湖边看断桥残雪"，v3 1901 说"木夫人当年也是爱极了杭州的景致"。
   - 执手本段的实际经过：
     - 子轩曾约"下雪时再来赏断桥残雪"（zs_1，执手250），但筱言自己想"一个人去"（1814）。
     - 初雪那天，子轩为了支开她抄家，让她"跟苏赫去看雪吧"（1929），她是和苏赫、巴特尔一起在冬至看的断桥（2053–2071）。
     - 她和子轩同在断桥，是岳百川夫妇双双亡故的那一夜（2357–2426），"为什么断桥未断，人却都走了？"（2371）。
   - 不算硬冲突。附注·全书检索：执手后文10667、11145、11273等处仍有"断桥"，可能另有合看的场面，待后段核。
   - 但这里有个可用的反差：如果阡陌将来从逍遥或凌云那里得知，"断桥残雪"在木夫人的记忆里其实是生离死别之夜，那比单纯的浪漫想象更有分量。
3. **年号（存疑）**
   - 执手的新皇年号是"元和"（zs_1，执手82）；v3 5751 写"太医院元祐某年的旧档"。
   - 如果 v3 临终的"伯父"就是执手本段登基的皇兄，那么二十年前的旧档应当是"元和某年"。
   - 除非 v3 有意安排中途改元或换了皇帝，建议 v3 5751 改为"元和"，或在正文交代改元。
4. **北庭与科萨**
   - 执手本段北方草原国一律叫"科萨国"（1496）；附注·全书检索：执手全书没有"北庭"二字。
   - v3 同时有"奉使北庭"（5735）和"科萨使团""科萨送来的公主"（5705、5767）。
   - 读者会问：北庭是科萨吗？建议统一成"奉使科萨"，或在一处点明"北庭即科萨王庭"。
5. **木夫人本人不懂医**
   - 执手1860"只可惜我不是学医的"。v3 173说《孤山十札》里有"医学杂项"，但她"早有言明，皆是先人所作"。
   - 这不矛盾，反而对得上：医学卷应是她凭现代常识转述的。
   - v3 若在别处把木夫人写成"通医"，就要小心。本段没有这样的反证，只作提醒。
6. **"二十年前"**：v3 5683"二十年前的旧事"，与执手的时间尺度大体吻合（元和元年子轩十八岁，zs_1）。执手本段内部"十六年/二十年"的出入（2189、2195）是前篇自己的问题，不影响 v3。

## 5. 可供陌陌扩充借用的素材（按 v3 位置）

**A. 杭州孤山、紫竹轩段（v3 5797–5870）：给逍遥一个"爹的杭州"**
- **湖畔"老地方"**（1476–1479）：临湖小馆，后院雅间开窗正对孤山；店主招呼"公子又来了，还是老地方么？"子轩只点铁观音。建议让逍遥带阡陌去这里。店家若还在，或换成后人，对逍遥说同一句"老地方么？"，两代人一句话就接上了。这一场可以补足 v3 杭州段的篇幅（v3全书"西湖"只出现1次，v3 1877）。
- **孤山大喊的秘密**（1444–1452）：子轩不开心时就找地方大喊，"只告诉过你一个人"。有两种用法：一是逍遥说"爹说，他有个秘密，只告诉过娘一个人"；二是逍遥"死讯"传来后（v3 5891），阡陌独上孤山，面对西湖喊出来（对照执手1447"我不是莫筱言"）。
- **苏轼孤山诗**（1469–1470）："孤山孤绝谁肯庐？道人有道山不孤。"适合放在碑前（v3 5807–5821），或放在逍遥"葬于孤山"的讣闻之后（v3 5891），一句就点题。
- **白堤到孤山的路线**（1443、1473）可作实景。

**B. 雪村与雪糕（v3 5327–5465）：给灵感找个来处**
- 在 v3 5353"就该拿雪做"之后，让逍遥补一句"舅舅当年也这么说过"（出自执手1797–1803，凌云的主意），就把赵凌云带进了这条情感线，也给卷四的京城段埋下伏笔。
- 执手1439：筱言郁闷时，大冷天也要吃雪糕。这可以让逍遥转述，说雪糕是娘"解闷的东西"，这层意思比现在更深。
- 模具的形状：桃形、梅花形（1651）。v3已用梅花，可补一只桃形，给念心或小阿枝。

**C. 星空与"欠一个故事"（执手1683–1786）：补一条贯穿卷二到卷五的暗线**
- 未兑现的两笔约定：子轩欠筱言"一个故事"（1756），筱言说"还有十一个星座，还有十一个故事"（1743）。v3 173说十札里有"天文"，可设想木夫人把十二星座的故事写进天文卷，写给子轩（存疑，属可选的构思）。逍遥夜里给阡陌讲射手座奇伦为朋友中箭而死的故事（1733–1735），正暗合逍遥"茶山中箭"（v3 5851）的命运。
- 北斗七星和北极星（1683、1720）可对上 v3 5209、5217 雪村的"七颗星"披肩：阡陌看披肩上的七星，逍遥指北极星，说"我娘教我爹认的"。
- 子轩的誓言"我们不会做相隔银河脉脉不得语的那两个人"（1774），可放进 v3 五年离别和墨韵斋段（v3 7151–7223），由逍遥自省：父亲守住了这句话，自己却做成了"盈盈一水间"。

**D. 科萨线（v3 5705、5767–5781）：萨仁名字的来历与还剑**
- 名字：执手的萨仁是科萨已故小公主（2117–2120），也是苏赫给筱言的名，意思是"草原上的月亮"。可让 v3 的萨仁自己说出名字的来历，例如"阿爸说，这名字从前给过一个杭州姑娘"。汗王是巴特尔还是苏赫，本段无法判断（存疑，看执手10376起的"可汗"）。
- 眼镜：执手1984–1986巴特尔问"眼镜是什么？"。v3可让萨仁说汗帐里流传一个"南边姑娘讲过的镜片"的说法，再由阡陌用宫叔叔杂记把它做出来。这样前后两代的知识就接上了，比现在"宫叔叔杂记"孤立的来源更动人。
- 还剑：萨仁的短剑（2100–2122）被筱言带走，还用它割过腕（2529）。如果执手后段交代剑留在紫竹轩（存疑，附注·全书检索：6254还提到这把剑），v3可以让逍遥从紫竹轩旧库（v3 5797）取出，由阡陌交还给新的萨仁，物归草原。这能给科萨线一个像样的收束。
- 未赴的约：筱言说"我会去找你们的，去吃烤全羊"（2128），巴特尔说"你若不来，我就派人把你抓了去"（2131）。阡陌去科萨客馆，等于替木夫人赴约，可点一句。

**E. 京城宫廷卷（v3 5643–5760）：用岳家旧案加厚"身世之争"**
- 王妃的出身：执手本段里，筱言是罪臣岳百川之女，判随家眷"入宫"（2413–2418）。宗正寺想扳倒逍遥，除了"不足七月"（v3 5735），还可以翻出"王妃乃罪臣之女、曾没入宫籍"，让阡陌在御前多一层要辩的。她拿出执手里"依律"与"皇兄宅心仁厚"特赦的旧案，就能回应。**罪臣女眷后来是否真入了宫、是否获赦，要看执手后段（存疑）。**
- 血亲姨母：芙蓉、玎宁是岳百川的女儿，也就是逍遥血缘上的姨母（2308）。她们进宫后的去向本段未交代（存疑）。如果执手后段她们留在宫中，v3可安排一位老宫人或太妃，就是当年的玎宁，给阡陌递话，比如讲锥心散"二十年前用过两回"的旧事（v3 5755）。
- 相国旧党：前朝相国是岳夫人的父亲，主谋并胁迫岳百川（2165、2318）。若 v3 需要给"三王爷"一方找个历史动机，这条旧党线可以借用。存疑，需与执手后段的南郡王线核对。

**F. 念心满月（v3 6469–6533）：三代长命锁**
- 羽君在女儿出生时挂上长命锁（2548），锁上刻"定不负相思意"（zs_1，执手812）；岳百川临死握着它（2215）。念心满月时，逍遥可打一把长命锁给她。刻不刻那五个字，要看作者想不想让负心旧事进门。或者由阡陌说一句"你外曾祖母给你祖母挂过一把"。原锁的去向，本段未交代。

**G. 赵凌云（v3 219–225、5643）：给"舅舅"一场重戏**
- 执手本段结尾的兄妹戏（2612–2629）口吻很鲜活："傻瓜""生命岂能由你儿戏""又多一个人要照顾，命苦啊"。v3京城段可让近四十岁的赵凌云对阡陌讲"你婆婆当年在济南做过一回傻事"，再说到逍遥的假死（v3 5891–5897），就把"逃避和面对"的母题交到下一代。逍遥回来时（v3 7179以后），可由舅舅说那句"生命岂能由你儿戏"。

**H. 逍遥的"逃避"，他母亲早给过答案**
- 执手第31章的核心：原主说"你还不能走，这一生你还没走完"（2543），"不要再逃避了，总要面对的"（2583）；羽君临终说"好好活着"（2575）；子轩说"你不是说你有你的责任么？…哪怕不顾及我"（2598）。
- v3里逍遥"死人最干净"（v3 7159）的自我说服，正是他母亲当年走过的弯路。阡陌找到墨韵斋时（v3 7179–7223），可以化用子轩那句"你好狠心…哪怕不顾及我"。

**I. 父子承袭的小动作**
- 子轩用中指轻点桌面谢茶（1482），揉眉心（1571、1923、2594），伸手替人揉开皱着的眉头（1433），给人夹菜（1517）。v3已写逍遥"眉心"（v3 4445、5247），可加一处他替阡陌揉开眉头，或在茶席上中指点桌。阡陌若见过赵凌云或皇帝做同样的动作，就能认出这是端木家的规矩。
- 揭面具时的台词：子轩说"我依旧是我，你还可以把我当作木先生，我还是子轩"（2161）。v3 2343–2375 逍遥摘下东篱面具那一场，可以让逍遥说出几乎一样的话，"我依旧是东篱"，形成父子对照。

**J. 年节与生活场景（补雪村过年，v3 5535–5600）**
- 冬至饺子"不冻耳朵"（2053）、捏八个褶的手艺（2062）、生日面（2501）、头七（2444）。这些都可以给雪村和紫竹轩的日常加一点温度。

## 6. 文笔观察（作者早期文风）

1. **第一人称穿越腔，现代口语密集**："脑子进水"（1839）、"花痴般看向他"（1391）、"飙车的感觉"（1603）、"无间道"（2176）、"梁山的军师——无用啊"（2017）、"现在是在拍戏么？"（2156）。好处是亲切、有喜感，毛病是出戏。
2. **诗词和歌词直接大段嵌入**：《沁园春·雪》全文（2085–2094），两段流行歌词各二三十行（1687–1714、2377–2395）。作用是渲染情绪，但会打断叙事的节奏。
3. **心理独白多，反问加省略号**：本段"……"出现135次，"仿佛"76次，"心下"35次，"难道"35次，"微微"26次，"怔了一怔"12次（按分块文件统计）。常见写法是一大段"为什么…为什么…"的自问（2375、2397）。
4. **靠光线和天气托情绪**：阳光象征安稳（1385），夕阳象征茫然（1529），雪象征净化或死亡（2071、2234、2371）。雪一直从"盼雪"铺到"满目血色"（2281），这条线处理得相当完整。
5. **生活细节和轻喜剧是亮点**：雪糕、分指手套、冬至饺子；冰山王子问"眼镜是什么？"，筱言答"总之就是让人看清楚的"（1986）；"我分你一个雪糕的一半"（1804）。这些最适合拿来给 v3 扩充。
6. **弱点**：
   - 靠巧合推进：去字画行取字，恰好认出父亲（1399）。
   - 解释性对白：岳夫人把前情一口气讲完（2296–2318）。
   - 口头禅重复。
   - 错字：岳白川×4（2186等）、"并为回答"（1482）、"就改怨你的"（2218）、"去满湖"（1469）、"夜班睡不着觉"（1971）、"郎然"（2611）、"命不久已"（2361）、"未曾层想"（1669）、"同的选择"（2243）。

**代表性短句**：
- "把你想说的话喊出来，心里就不会憋闷了。"（1444）：台词短，动作感强，是子轩的性格标签。
- "我在想，仿佛几万年前，我见过你。"（1487）：穿越和前世的母题一笔带过，为第31章"前世"作伏笔。
- "那雪糕，很好吃。"（2014）：冰山人物一句软话，反差就出来了。
- "为什么断桥未断，人却都走了？"（2371）：地名双关，点题，是本段最好的一句。

**与 v3 对照的建议**：v3 已经转向克制的短句（如 v3 5657"殿里静了一瞬"），比执手成熟得多。扩充卷二到卷五时，**从执手借"物件、场景、台词、生活细节、轻喜剧的反差"**，比如雪糕、湖畔老地方、孤山大喊、冰山王子、饺子八个褶；**不借它的长段自问自答和整首诗词嵌入**。一首诗在 v3 里最多取一两句，放在人物口中或碑上，效果最好。
