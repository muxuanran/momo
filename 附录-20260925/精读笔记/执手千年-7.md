**本段一句话**：六月十五宫变，临风用淬了锥心散的剑误伤筱言。筱言大难不死，临风被废为庶人后离京。七夕那天玎宁远嫁科萨，子轩送玉猪求婚，两人于元和二年七月二十六成婚。中秋、香山、满月宴三场写婚后日常。子轩和凌云北上巡视期间，筱言得知临风当初是替她"过毒"才耗尽了自己，她赶往西北，陪临风走完最后一程，临风死在焰火和初雪里。璎珞抱着他的尸身走进塞外的大雪。

**章号问题**：原文标到"第一百章"，但"第九十二章"（8368、8417）和"第九十九章"（9088、9236）各重复了一次，实际共有21个章题。

## 2. 人物设定事实表

### 莫筱言（女主，就是陌陌里的"木夫人"、紫竹轩主人）
- **称呼**：临风叫她"言"（7586）；睿亲王妃、夫人（8466、8400）；宫变那天她自称"南亲王妃"（7683）；璎珞口中的"书库的莫筱言"（9443）；她说自己不再是"那个宫女儿"（8074）。
- **出身**：生母是莫羽君（7629–7630）；和玎宁的关系"就像你同子轩"，也就是同父异母（7631）；宫里传她是"总督的私生女"（8476），说她娘"未婚先有孕"（8478）；她叫凌云"哥"（8060）。
- **穿越者底色**：说自己"受现代教育多年"（7753）；讲星座（8117）；从现代带来的月饼做法（8436）、流行歌（8523）；"计算机"（8537）；想象千年以后的世界（8763）。
- **性格**：爱说笑、嘴不饶人（8269–8270）；不喜欢宫廷（8971），但被人欺负时会反击（8516–8525）；心软，求子轩救临风（7793）；她自己的信条是"我只是希望大家都好"（9053）。
- **身体（与陌陌关系最大）**：胸口受的是锥心散剑伤（7758）；余毒没清干净（7872、9118）；阴雨天旧伤会痛（7874、8988）；两臂各有一道导毒的切口（7993）；体质寒凉，怕冷（7583、8805、8822、9068）；红叶一直在隐瞒什么（8250–8251、8659）；她自己也觉得来日无多："我的生命里又有多少个黄昏可看呢"（8058）。
- **疑似怀孕（推测）**：婚后"身子乏得紧"（8420）；在西北"心口泛恶心，头更加晕了"（9314）。本段没有明写。
- **随身物**：玉猪（8171–8180）；朝凤钗（8414）；绣萤火虫的帕子（8967）；湖心石（8221、8856）；海棠盆（8020、9094，已摔碎）。
- **本段结局**：活着，人在西北，刚为临风送完终。

### 端木子轩（睿亲王，也就是陌陌里的"木先生"、先睿亲王）
- **称呼**：睿亲王（8159、8269）；临风叫他"二哥"（9383）；初见时筱言叫他"木先生"（8315）；她婚后称他"夫君"（8409）；科萨王子叫他"端木兄"（8217）。
- **关系**：太后的儿子（8173"母后"）；皇帝端木子俊的弟弟（8173"皇兄"）；凌云的妹夫。
- **外貌与癖好**：初见时穿月白长衫，眼神温和（8314）；爱喝铁观音（8576）；会点穴（7764）；喜欢安静（8434）。
- **关键经历**：宫变那天是一场假婚，他穿着新郎装（7715、7879）；求婚（8140）；送玉猪（8173–8180）；七月二十六成婚（8321）；亲手做拨浪鼓（8884）；九月和凌云去漠北、西北巡视，要顺路去科萨、看秀儿（8816–8828）。
- **许诺**："我们要在那里盖座小房子，夏天看看满池荷花，冬日看漫天飘雪"（7819）；"咱们便可以去看西湖的雪景了……孤山梅花"（8833–8837）；"等这次回来，咱们就去杭州，就去找咱们的梦"（9126）。
- **本段结局**：活着，仍在北边，没有回来。

### 端木临风（南亲王，后来被废为庶人）
- **称呼**：端木临风（7732）；南亲王（7884）；子轩叫他"四弟"（7715）；璎珞叫他"主子"，临死时改口叫"风"（9101、9436）。

- **生死**：第100章死在西北（9392）。璎珞抱着他的尸身去了塞外，消失在大雪里（9445）。**葬在哪里本段没有交代**。

### ② 相冲（两边说法对不上）

1. **临风的身份**
   - v3 5683："先睿亲王妃与**江南名士**临风'文墨往还、过从甚密'"。
   - 执手：临风是端木临风（7732），子轩的"四弟"（7715），南亲王（7884），后来贬为庶民（7888）。"江南"只和他的母亲有关（7593）。
   - v3 自己也前后不一：5753又写作"南郡王"。
   - 建议：改成"废南亲王临风"或"庶人端木临风"。改了以后流言性质会变：逍遥无论是谁的儿子都是端木血脉，要问的就成了"是亲王之子，还是废庶人、谋逆者之子"。这对宗正寺更有杀伤力，逍遥辞去监国也就更顺理成章。

2. **"南郡王"与"南亲王"**
   - v3 5753作"南郡王"。执手本段宫变时他是"南亲王"（7683、7742、7884）。附注：据 zs_4 笔记，他先是南郡王，后来升为南亲王（执手3785）。
   - "败走"也不准确。执手里谋反的主谋是晟亲王（7722–7725）。临风是被利用后收了手，皇帝把他贬为庶民，他随后离开（7888）。
   - 建议：写"废南亲王"；或者让阡陌把晟亲王的事一起点出来。

3. **锥心散的来历和次数**
   - v3 5755："此毒出自宫闱，**二十年前**用过两回。"
   - 执手：方子出自"殷家"毒经（9189），宁和宫那次是璎珞重配的（7778）。第一回用在临风母亲身上，比宫变早了一辈人，那时临风还小（7604–7605）。第二回才是二十年前的宁和宫。此外临风为筱言过毒，自己也死于这毒（9117）。
   - 建议：改成"此毒前后用过两回，一回在先帝朝，一回在二十年前的宁和宫"。

4. **年号**
   - v3 5751："太医院**元祐**某年的旧档。"
   - 执手作"元和"（8321）。全书检索"元祐"为0。
   - 建议：改为"元和"；或者交代新帝已经改元，而旧档仍按元和纪年。

5. **"奉使北庭，去国八月"**
   - v3 5735的说法。执手本段是去漠北、西北"例行巡视"，顺路去科萨（8816–8828），子轩预计"少则一月"，最多两个月（8829）；小荷说"再过月半就能回来"（9038）。
   - 地名不一样。时长能否对上要看后段（zs_8）有没有写他滞留：**存疑**。
   - 如果后段没有延期，建议把 v3 改成"奉旨巡边，经年未归"之类较模糊的写法，或者直接用"漠北"。

6. **"汗王"**
   - v3 5767的称呼。执手本段科萨国君被称作"父皇"（7940）、"科萨国王"（8202）。小问题，统一一下就好。

7. **流言漏掉了最真实的把柄（这不是矛盾，但 v3 的漏洞比矛盾更大）**
   - 执手本段写得很清楚：子轩北上期间，筱言私自"上了西去的车马"（9233），在西北临风那里住了好几天，陪他到死（9312、9392）。孕象也正是这时出现的（9314）。
   - 再加上丽贵妃早就放出的"睿亲王这帽子戴的……"（8479）。
   - v3 宗正寺那场（5735–5755）只算了月份，没有拿这件事来发难。阡陌的反驳也只靠脉案。见第5节第1条建议。

8. **"三王爷"**（v3 5737、5755，他在"锥心散"三字上停了手）
   - 执手本段害死临风母亲、挑动宫变的是晟亲王高晟（7722–7734），行三的王爷本段根本没出场。
   - 这一条算"本段未见"。但如果 v3 要让三王爷心虚，需要补一句他和晟亲王一党的关系。

## 5. 可供陌陌扩充借用的素材

以下按对 v3 的价值排序，每条写明可以放在哪里。

1. **宗正寺一场可以加一记重拳，由阡陌化解**（v3 第37章，5735–5755）
   - 素材：丽贵妃放出的流言（8470–8482）；筱言在夫君北上期间私下西行探望废南亲王，还在那里出现孕象（8802–8829、9233、9314）；临风为她过毒（9116–9118）。
   - 用法：宗正寺卿第二刀抛出"王妃曾私赴西北，与废南亲王同处数日"。阡陌的回答是：那一趟是去送一个为她换血过毒、将死的人。孕象早在京中就有了，红叶手录的脉案可以作证。"诸位拿来做文章的，是一条命换一条命。"
   - 这样"临风之子"的流言就从羞辱变成恩义。卷四也凭空多出一场高潮。

2. **"去云南找神医"，隔一代由阡陌应验**（9356）
   - 筱言在绝望中说"或者去云南"，没有来得及。陌陌的女主正是大理医女。
   - 可以在逍遥视角（番外，v3 6955附近）写一句："娘当年说过要去云南找神医。她没去成，我替她去了。"这是两部书之间最省字、也最动人的一道缝。

3. **玉猪的来历可以一次讲清**（8171–8180）
   - v3 6683写玉猪"谁也说不上来历"，正好留出揭晓的空间。
   - 建议：阡陌或逍遥在月下举起玉猪，看见透出来的"轩，言"二字，翻到背面是"执子之手，与子偕老"。
   - 玉料来自太后赐的一对镯子，"一只给了皇兄"（8173）。v3 端木京病榻那场（5657）可以让皇帝拿出另一只镯子，这就是亲王夫妇信物的旁证，情理上胜过谱牒。
   - v3 6533的婚礼供案上也可以添上玉猪。

4. **拨浪鼓，父子两代**（8883–8884；v3 6429）
   - 子轩为"以后的孩子"做了拨浪鼓，却被筱言拿去送给了长公主佩儿（8917）。
   - v3 可以让佩儿（这时二十岁上下，推测）把旧鼓还给逍遥："这原是你的。"或者只让逍遥雕鼓时想起舅母说过的这件事。

5. **"未竟之约"的母题**
   - 子轩许诺"等我回来……西湖的雪景……孤山梅花"（8833–8837）、"就去杭州，就去找咱们的梦"（9126）。
   - v3 5949逍遥"第四样，'回去'，你自己赖了账"，是同一种约。
   - 建议：卷四孤山篇（v3 5797–5815）让逍遥说出父亲当年这句话。父子两代都许了"回来"，结果都差点失约，前后对照。

6. **西湖小房子，也就是紫竹轩的蓝图**（7819–7821）
   - "夏天看满池荷花，冬日看漫天飘雪……听雨打荷叶……围炉煮酒"，再加上"一杯香茗，一卷书"（7818）。
   - v3 写紫竹轩（5797、5833–5851）时可以照这张单子布景：荷塘、火炉、香茗、书卷。阡陌一见便知"是娘的梦"。

7. **殷家毒经、过毒之法与 v3 的《千机毒经》**（9189、9116–9117；v3 6407、6415）
   - 过毒要"功力深厚之人"来做，代价是施救者自己的性命（9351）。
   - v3 卷五阡陌为逍遥延命时，可以让她在毒经里读到这种"以命换命"的法子。逍遥以临风当年的话拒绝她："我不要她为救我而丧命。"这是前后两代的镜像。
   - 《千机毒经》是否就是殷家毒经，可以作为伏笔（推测）。

8. **科萨的回命丹、湖心石和骑马之约**（7936、8221–8224、7959–7961、8226）
   - v3 科萨使团和萨仁那几场（5705–5781）可以加：萨仁认出紫竹轩旧库里那块湖心石，"我们草原的石头"；萨仁转述父汗的话："当年有个中原女子说要来草原学骑马，她没来。"
   - 这样萨仁和前篇就接上了。萨仁的父亲推测是巴特尔（他在杭州和筱言看过雪，7958）。如果安排成苏赫和玎宁的女儿，她就是逍遥的表妹，也是一个可选的转折。

9. **静安和慈心庵，一位活证人**（8661–8752）
   - 安安在香山带发修行，二十年后大约四十岁（推测）。她知道晟亲王怎样害死临风的母亲、宁和宫那天发生了什么。
   - v3 端木京篇（5643–5760）篇幅偏薄，可以加一场阡陌上香山求证，给5755"殿上年长的大人们——都记得"找到一个具体的人。
   - 静安念的偈"一念心清静，莲花处处开"（8680），也可以和 v3 6429鼓柄上的莲相呼应。

10. **京中故人群像，可以用来加厚卷四**
    - 芙蓉：逍遥的姨母，常在宫里，得皇帝宠爱（8090），是现成的内应。
    - 小青：筱言当姐姐的丫鬟，曾在睿亲王府（8400），可作府中旧人。
    - 小荷：会做点心（8436），能做出"娘的月饼"。
    - 长公主佩儿（8909）。
    - 德公公（8334）。
    - 忆月阁一直有人打扫（8980），逍遥可以夜里独自去一趟，面对"临风"这个名字。

11. **海棠：断肠红／相思红**（9019、9094、9130）
    - v3 萨仁说阡陌脸上是"野海棠"（5715），v3 1959有海棠。
    - 可以让逍遥知道这个典故（《孤山十札》里录有陆游、唐婉的故事），听萨仁一说脸色一变，读者便懂了。

12. **临风的去向，一条没收的线**（9443–9445）
    - 璎珞抱尸入塞外，葬在哪里不明，璎珞和石伯的下落也不明。
    - v3 雁回关外逍遥"把端木逍遥……一起葬了"（7151）和临风消失在塞外大雪里，暗暗对应。
    - 可以选择在雁回关外添一座无名的土丘，守墓的是一个眉心有红痣的疯妇人（红痣据 zs_4 笔记）。点到为止，不必说破。这一条是建议，原文没有。

13. **天煞孤星的诅咒**（7770）
    - "你最亲人都将会是你亲手杀死的"。v3 7159逍遥"死人最干净"的自我放逐，心理上是同一种恐惧。
    - 可以借这句咒语，写逍遥怕自己连累阡陌。

14. **节令与生活细节，适合卷二、卷三的日常段落和番外**
    - 凤仙花染指甲，听捣花声辨心性（8786）。
    - 蛋黄月饼，可作十札"杂项"里的方子（8508–8510）。
    - 绿豆糕配铁观音，可作夫妻两人的口味标签（8575–8576）。
    - 香山红叶"满山都是你的名字"（8636）。
    - 婚俗细节：背轿、红绸、合卺、梳惊鹄髻（8324–8414）。

15. **红叶的义诊药铺**（8200）
    - 和阡陌的免费书院（v3 643）、雪村行医遥相呼应。
    - 舅母红叶可以成为阡陌医道的"前辈影子"。v3 6683箱子里"舅母的遗物"除了旧砚，还可以加一册红叶手录的脉案（建议）。

**注意**：执手里的现代歌词（《花好月圆夜》《沧海一声笑》、8290–8313那首和9146–9183）不宜整段搬进陌陌，有版权风险，写法上也显得突兀。v3 955"木夫人的曲谱"保持虚写就好。

## 6. 文笔观察（作者早期文风）

- **第一人称穿越腔，现代词随手嵌进古代**：
  - 7583"难得能在没有空调的日子里自己做了会空调，岂不知足。"
  - 8154"没有玫瑰，每月钻戒，只有这一片月光，满园花香"（"每月"当作"没有"）
  - 8494"原来电视剧里面演的都是真的"
  - 8629"看猪在飞！"

  幽默来自身份反差和撒娇式斗嘴（8581"快拿使用费来"）。
- **诗词引用密集，常常整首照录**：一章之内会录完整首词，例如《钗头凤》两首（9022–9034）、《声声慢》（9132–9137）。诗词多是借来烘托情绪，很少化进叙事里。
- **心理独白靠排比和反问推进**：8048"我记得的，一起看过的那场焰火，一同弹过的曲子，一起赏过的桃花"。"为什么，为什么"反复出现（9119、9127）。感叹号连用，有时一连四五个（7635、7754）。
- **描写习惯**：
  - 用天气定情绪，宫变后的雨（7831）、秋雨（8986）、临风死时的初雪（9429）。
  - 用颜色作对照，婚礼的红和血的红（7715"满眼的红色像血一般的刺眼"），灵堂的白（9413）。
  - 结构上用"一件物事牵一个人"：海棠牵临风，玉猪牵子轩，拨浪鼓牵孩子，手套牵初遇。收束一段情节时，常用一个意象落地，例如9130"只剩下满地海棠花，似血一般，散落一地红"。
- **网络连载留下的痕迹**：作者按语和 mp3 链接（9139–9144）；章号重复（8368/8417、9088/9236）；错字较多，如"萃毒"（7746）、"手仞"（7753）、"雷锋夕照"（8836）、"汉河女"（8118）、"红邑鲛绡"（9025）、"走运"（9445，当作"走远"）。
- **和 v3 的对照**：v3 的文风克制、留白，例如5755"殿里的静，换了一种质地"。执手则外放、直给。扩写陌陌时，建议借执手的**物件链、节令生活和群像**，不要借它的感叹号密度和整首录诗的做法。执手里写得最好的地方也在克制处，比如9304–9307临风只说了一句"你梳了髻……很好看"，比大段哭喊更有力，值得学的正是这一类。
